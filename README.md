# SEHI 홈페이지 (Jekyll / GitHub Pages)

## 구조
| 경로 | 역할 |
|---|---|
| `_config.yml` | 사이트 제목, 회사 정보(주소·전화·이메일) |
| `_data/menu.yml` | 상단 메뉴 · 서브메뉴 구조 |
| `_layouts/default.html` | 모든 페이지 공통 틀 (head + 헤더 + 본문 + 푸터) |
| `_layouts/sub.html` | 서브페이지 틀 (상단 타이틀 + 서브메뉴 + 위치표시) |
| `_includes/` | 헤더, 로고, 푸터, 하단 바로가기, 상담 CTA 조각 |
| `*.html` | 각 페이지 본문만 들어 있음 |
| `assets/css`, `assets/js` | 스타일, 스크립트 |

## 공지사항 글쓰기
`_notices` 폴더에 파일을 하나 추가하면 공지가 하나 올라갑니다. 목록·번호·상세 페이지·메인 화면 공지 한 줄은 자동으로 바뀝니다.

1. 파일 이름은 **영문·숫자·하이픈**으로 지정 (예: `_notices/yearend-2026.md`). 이 이름이 글 주소가 됩니다 → `/notice/yearend-2026.html`
2. 맨 위에 머리말, 그 아래에 본문 작성

```
---
title: "[SEHI] 2026년 귀속 연말정산 안내입니다."
date: 2026-11-20
pinned: true        # 맨 위 '공지' 배지로 고정할 때만 (없으면 일반 글)
---
본문을 여기에 씁니다. 빈 줄로 문단을 나눕니다.

**굵게**, [링크](https://blog.naver.com/sehi0403), 이미지 ![설명](/images/파일명.jpg)
```

- 본문을 비워 두면 목록에 제목만 나오고 클릭되지 않습니다.
- `hide_date: true`를 넣으면 날짜가 `-`로 표시됩니다(날짜를 모르는 옛 글용).
- 글 삭제는 파일을 지우면 됩니다. 수정·삭제 모두 푸시 후 1~2분 뒤 반영됩니다.

## 자주 하는 수정
- 전화번호·주소 변경 → `_config.yml`의 `company`만 수정
- 메뉴 추가 → `_data/menu.yml`에 한 줄 추가 + 새 페이지 파일 생성
- 새 페이지 → 아래처럼 맨 위에 머리말을 넣고 본문만 작성

```
---
layout: sub
title: "페이지 제목"
group: "About SEHI"   # menu.yml의 name과 같아야 서브메뉴가 나옴
---
<p>본문</p>
```
